# Process ACH Payouts

Now that you have completed the [Collect Bank Accounts](/guides/payment-methods/collect-bank-accounts) guide, let's process an ACH payout with the newly captured bank account.

## Getting Started

<GettingStartedSection />

### Get your Secret Key

Next you will need your `Secret Key`. [Go to your Developers section](https://portal.publicsquare.com/developers/api-keys) and click `Reveal` for your `Secret Key` and copy the value.

<Alert>Save the Secret Key as it will be used in the next steps of this guide.</Alert>

## Payout Types

Bank account payouts are sent over one of three rails, selected with the optional `payout_type` field. If you omit it, the payout is sent as `standard`.

| `payout_type` | Rail | Speed | Requirements |
| --- | --- | --- | --- |
| `standard` | ACH credit | Settles on the next banking day | Your account is onboarded for payouts |
| `same_day` | Same-day ACH credit | Settles the same banking day when submitted before the cutoff | Your account is onboarded for payouts, and the receiving bank supports same-day ACH |
| `instant` | RTP (Real-Time Payments) | Settles in seconds, including weekends and holidays | Instant Payouts is enabled on your account, your account is onboarded for RTP, and the receiving bank participates in the RTP network |

<Alert>
  Instant Payouts is off by default. [Request access from your account settings](https://portal.publicsquare.com/settings) to enable it.
</Alert>

### Create a Payout

We need to make a call to [Create Payout](/api/financial/create-payout) endpoint:

```shell showLineNumbers title="Create a Payout"
curl 'https://api.publicsquare.com/payouts' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPONTENCY-KEY: '09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payout_type": "standard",
  "payment_method": {
    "bank_account": "ba_7Ay5mcUXAxwrN6wQEQUVEHBCJ"
  },
  "customer": {
    "first_name": "John",
    "last_name": "Smith",
    "email": "john.smith@email.com"
  },
  "billing_details": {
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",
    "country": "US"
  }
}'
```

<Alert>The amount is provided in cents. 1000 is the equivalent of $10.00</Alert>

<Alert type="warning">The IDEMPONTENCY-KEY header can be passed to protect against duplicate payouts being processed.</Alert>

### Create an Instant (RTP) Payout

To send the funds over RTP instead of ACH, pass `instant` as the `payout_type`. The recipient typically receives the funds within seconds, any day of the week:

```shell showLineNumbers title="Create an Instant Payout"
curl 'https://api.publicsquare.com/payouts' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPONTENCY-KEY: '09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payout_type": "instant",
  "payment_method": {
    "bank_account": "ba_7Ay5mcUXAxwrN6wQEQUVEHBCJ"
  }
}'
```

<Alert type="warning">
  Instant payouts require Instant Payouts to be enabled on your account. If it is not, the payout is rejected with a `Configuration Error`.
</Alert>

```shell showLineNumbers title="Instant Payouts not enabled"
{
  "title": "Configuration Error",
  "status": 400,
  "detail": "instant payouts are not enabled for this account. Please request access at https://portal.publicsquare.com/settings"
}
```

If the receiving bank does not participate in the RTP network, the payout is rejected with a `payment method does not support instant payouts` detail. Send those payouts as `standard` or `same_day` instead.

### Create a Same-Day ACH Payout

Same-day ACH settles faster than standard ACH without requiring RTP support, as long as the payout is submitted before the same-day cutoff and the receiving bank supports it:

```shell showLineNumbers title="Create a Same-Day Payout"
curl 'https://api.publicsquare.com/payouts' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPONTENCY-KEY: '09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payout_type": "same_day",
  "payment_method": {
    "bank_account": "ba_7Ay5mcUXAxwrN6wQEQUVEHBCJ"
  }
}'
```

### Create with Existing Customer

If you [created a customer](/api/accounts/create-customer), then you can pass the `customer_id` when processing the payout:

```shell showLineNumbers title="Create a Payout with Customer"
curl 'https://api.publicsquare.com/payouts' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPONTENCY-KEY: '09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payment_method": {
    "bank_account": "ba_7Ay5mcUXAxwrN6wQEQUVEHBCJ"
  },
  "customer": {
    "customer_id": "cus_7Ay5mcUXAxwrN6wQEQUVEHBCJ"
  },
  "billing_details": {
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",
    "country": "US"
  }
}'
```

### Create with Customer's Payment Method

If you [attached the bank account to a customer](/api/financial/attach-bank-account-to-customer), then you can omit the `customer` section when processing the payout:

```shell showLineNumbers title="Create a Payout with Payment Method"
curl 'https://api.publicsquare.com/payouts' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \

-H 'Content-Type: application/json' \
-d '{

  "currency": "USD",
  "payment_method": {
    "bank_account": "ba_7Ay5mcUXAxwrN6wQEQUVEHBCJ"

    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",
    "country": "US"
  }
}'
```

### Create with Payment Method's Billing Details

If you supplied the `billing_details` or [updated the bank account](/api/financial/update-bank-account), then you can omit the `billing_details` section when processing the payout:

```shell showLineNumbers title="Create a Payout with Payment Method"
curl 'https://api.publicsquare.com/payouts' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPONTENCY-KEY: '09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payment_method": {
    "bank_account": "ba_7Ay5mcUXAxwrN6wQEQUVEHBCJ"
  }
}'
```
